# Codex 预热与续聊

**v0.6.0 · 实验性停更快照 · Windows · MIT**

这是一个非官方的 Codex 本地插件，用于查看额度、安排预热，以及在额度恢复后向用户明确选择的对话发送预先保存的消息。项目停止主动维护，公开源码供学习和参考；不保证后续 Codex、模型或额度规则的兼容性，也不是 OpenAI 官方产品或商店审核通过的插件。

**它不会增加额度、绕过限额、购买额度或兑换重置次数。预热会消耗订阅额度，不能保证开启新的服务器窗口。** 请自行确认平台现行条款和自动化规则后决定是否使用。

## 功能

- 原生导航中的白色“预热管理”页面，不使用系统托盘、外置窗口或浏览器标签页。
- 约每 60 秒通过官方 CLI 读取额度元数据；满足条件后才执行独立的 `gpt-5.6-luna` / `low` 预热请求，不改其他对话的模型。
- 用户选择对话、设置独立消息，支持单次、每次恢复后重复或指定次数；可以取消、编辑、移除。
- 区分真实额度中断的恢复与用户明确安排的下一周期预输入；后者允许上一轮正常完成。
- 运行中、已知等待审批/输入、主动暂停、归档、未知状态等情况不投递；结果不明不自动重发。
- 后台进程诊断、插件重载时的有限恢复；可选登录自启，不唤醒睡眠电脑、不自动打开 Codex。
- 可选 3% / 5% 低额度提醒，默认关闭，需要使用者审阅并信任 Hook。
- 可选 Aion 恢复桥适配；桥项目及其凭据、讨论数据不包含在此仓库中。

详细使用方法、状态存储、风险和卸载步骤见 [插件说明](codex-warmup/README.md)。

## 使用前提

- Windows 10 / 11；Python 3.10+，并且 `python` 可从 PATH 调用。
- 已安装并登录的官方 Codex CLI；插件不代装 CLI、不代登录、不要求 API Key 或 Cookie。
- 支持 MCP Extensions 的桌面客户端。开发时验证的组合为 Codex CLI `0.165.0-alpha.1.2`、桌面版 `26.1023.6123.0`、Python `3.13.1`；这不是对其他版本的兼容承诺。
- 额度接口须明确返回 300 分钟主窗口和有效周窗口。模型不可用、登录失效、结构变化或额度未知时应等待，而不是发送探针绕过检查。

普通使用无需 Node.js 或前端依赖，仓库中包含已构建的管理页面。**未做另一台 Windows 电脑的迁移实测。**

## 安装

下载仓库 ZIP 并解压到准备长期保留的目录，或执行：

```powershell
git clone https://github.com/WangJamesWilde/codex-warmup.git
cd codex-warmup
.\install.ps1
```

先审阅脚本和 Hook 再执行。默认安装不主动开启预热或登录自启，不需要管理员权限，不会自动放宽 PowerShell 执行策略。若系统策略阻止脚本，请先审阅并自行决定如何按本机策略运行，不使用绕过开关。

安装后，在 Codex 左侧导航或“更多”里打开“预热管理”，明确启用后台，并只添加自己希望自动续聊的对话。Hook 信任需要另外确认，管理页开关不代替宿主审阅。

脚本的 `-Enable` 明确允许在符合条件时消耗订阅额度；`-LoginStart` 明确注册当前用户的登录启动项。**不要为了试用运行带这些选项的命令。** 状态目录遵循 `CODEX_WARMUP_HOME`、现有注册表映射或 `%LOCALAPPDATA%\CodexWarmup`；不要提交或分享其中的数据。以前安装过其他发行副本的用户，请先检查已有映射，避免同时运行多套后台。

公开副本的本地市场名为 `codex-warmup-local`，插件标识为 `codex-warmup@codex-warmup-local`。插件缓存按官方流程安装在用户目录中；本仓库不附带 Python、CLI、登录状态或整套开发环境。

## 测试

在仓库根目录执行：

```powershell
New-Item -ItemType Directory -Force .state | Out-Null
cd codex-warmup
python -B -m unittest discover -v
```

测试使用模拟额度、独立临时数据库及无模型的进程夹具，不需要真实消息发送。两个跨项目桥接测试需要另外提供 `CODEX_WARMUP_BRIDGE_SOURCE` 和 Node.js，未提供时会跳过；该外部桥源码不是普通使用的必需依赖。

这些测试不等于真实自然重置、跨机器迁移或长期无人值守验收。原生入口及有限的人工授权消息链路曾在开发环境验证，但新版本、其他账户和设备仍需自行审阅验证。低额度 Hook 的真实宿主投递也不应当作已全面验证。

2026-11-01 发布副本验证：发现 160 项测试，158 项通过，2 项可选跨项目桥接测试因未提供外部源码而跳过，0 失败；安装脚本通过 PowerShell 语法检查。没有重新安装到正在使用的 Codex，也没有发送真实测试消息。

## 前端开发

仅需修改界面时才安装 Node.js 和 pnpm，在 `ui-build` 中执行 `pnpm install --frozen-lockfile --ignore-scripts` 和 `node build.mjs`。`node build.mjs --qa` 还会生成使用虚构数据的离线演示页；它不代表真实账号额度或完整桌面端端到端测试。
